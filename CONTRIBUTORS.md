## How contributions are recorded

- Each person commits from their own clone with their own Git identity and pushes with their own GitHub account, one branch and pull request per task, reviewed by the lead.
- Existing history is preserved. No commit is created, split or re-authored to adjust attribution.
- If someone contributed in a way Git does not show (reviews, testing, design input), it is recorded here with a link to the evidence.
